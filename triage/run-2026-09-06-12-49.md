## Lead 1: `api.obi.com` seller-data-hub-service `/public/` Unauthenticated Seller Registry + CORS Wildcard

| Q | Answer |
|---|--------|
| Q1 In scope? | **Yes** — `api.obi.com` is an OBI-owned MuleSoft gateway discovered in passive recon; seller-data-hub-service is a child service on this gateway. |
| Q2 Reachable? | **Yes** — `/public/de/feature-toggle`, `/public/{cc}/seller-side-panel/{trxId}`, `/public/imprint-documents/{key}/{cp\|gtc}` all return HTTP 200 with no authentication from the public internet. |
| Q3 Real impact? | **Yes** — Full seller PII/business data (imprint, settings, bio certificates, shipping thresholds) enumerable via sequential trxId (dense block ~100000–100550) across 6 countries (DE/AT/IT/PL/FR/ES). 15 internal `SOA.*` feature flags and project names exposed. CORS reflects arbitrary `Origin` with `Access-Control-Allow-Credentials: true`, enabling any website to make credentialed cross-origin reads of seller registry data. |
| Q4 Provable non-invasively? | **Yes** — `curl -H "Origin: https://evil.example" https://api.obi.com/trx-api/fulfillmentsellersteering/seller-data-hub-service/api/v1/public/de/feature-toggle` returns 200 + `ACAO: https://evil.example` + `ACAC: true`. Sequential GETs to `/public/de/seller-side-panel/{id}` enumerate sellers. All passive, no auth required. |
| Q5 Novel? | **Yes** — Knowledge base confirms: exposure is UNIQUE to seller-data-hub-service (own `/api/v1/` mirror is 401, all 7 sibling services' `/v1/public/` are 401 mule-realm). Not a platform default. |
| Q6 On always-rejected list? | **No** — This is a fresh finding; not rejected in any prior triage run. |
| Q7 Reasonable triager? | **Yes** — Unauthenticated PII registry + CORS ACAC on a production marketplace is a clear vulnerability. |

**Verdict: VALID**

- **Proof steps:** `curl` GET to 3 `/public/` endpoints (feature-toggle, seller-side-panel/1, imprint-documents/obiecomprod/gtc); `curl -H "Origin: https://evil.com"` to verify CORS reflection; sequential GETs to `/public/de/seller-side-panel/{100000..100550}` to show enumeration. All read-only, no auth.
- **Impact:** Unauthenticated exposure of seller business registration data (company imprint, bio certificates, shipping config) and internal feature flags for 6 European markets. Any-origin CORS allows attacker-controlled website to exfiltrate this data via JavaScript.
- **CVSS 3.1:** **6.5 (Medium)** — AV:N/AC:L/PR:N/UI:N/S:U/C:L/I:L/A:N (information disclosure via misconfigured CORS on authenticated-adjacent resource)
- **Reporting channel:** `bugs.olivermaicher.eu` — report to OBI program, referencing seller-data-hub `/public/` registry and CORS ACAC misconfiguration.
